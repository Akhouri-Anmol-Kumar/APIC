<h1 align="center">🙋 FAQ</h1>

<details>
<summary><b>Do I need to install Python?</b></summary>
<br>
No. Download the release ZIP, extract it, and run <code>APIC.exe</code>. Python is only needed if you want to run from source.
</details>

<details>
<summary><b>Does APIC upload my images anywhere?</b></summary>
<br>
No. APIC is 100% offline. All processing happens locally on your PC.
</details>

<details>
<summary><b>Is it free?</b></summary>
<br>
Yes, and it has zero ads.
</details>

<details>
<summary><b>Can I convert a whole folder at once?</b></summary>
<br>
Yes. Batch conversion lets you convert an entire folder in one go.
</details>

<details>
<summary><b>Windows shows a warning when I run the .exe. Is that normal?</b></summary>
<br>
Windows can show a SmartScreen prompt for apps from smaller independent developers. If you downloaded APIC from this repository's Releases page, you can choose <b>More info → Run anyway</b>.
</details>
